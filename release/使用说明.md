# Codex 会话删除工具

适用于 Windows 10 / 11 x64。双击同目录的 `CodexSessionCleaner.exe` 即可运行，无需安装其他运行库。

程序自动递归扫描 `%USERPROFILE%\.codex\sessions`。左侧只列出交互主会话，按修改时间从新到旧排列，隐藏子 Agent 和非交互会话；数量只统计主会话。选择后，底部显示完整路径，右侧显示前 5 条用户及助手文字消息。

预览隐藏 `<INSTRUCTIONS>...</INSTRUCTIONS>` 和 `<environment_context>...</environment_context>` 区块（含标签），过滤后仅剩空白的消息跳过，不占用前 5 条名额；原始文件不变。预览支持滚动、自动换行、选中后 Ctrl+C 复制，以及 Ctrl+A 全选。点击“刷新”重新扫描。

核对完整路径后点击“删除选中会话…”。确认弹窗默认选择“取消”。选择“确定”会永久删除该主会话及其所有层级的子 Agent 文件，不经过回收站，无法撤销。删除前会重新扫描，跨日期目录查找子会话；普通 fork 产生的独立主会话不受影响。成功后更新列表并清空预览；失败时保留主会话列表项，报告已删除数量及失败原因，可重试完成剩余清理。

本版只删除所选主会话及其子 Agent 的 JSONL 文件，不修改 Codex 索引、history.jsonl 或数据库，也不保证清除其他界面中缓存的历史条目。

列表按 session_meta.source 筛选 cli / vscode 主会话，与 resume --all 的交互会话范围对应；归档状态或缓存仍可能造成数量不同。元数据缺失、损坏或无法读取的文件会跳过并提示，删除时遇到元数据错误或重复 ID 则停止操作。

如果中间层子文件已丢失，其更深层后代可能无法关联。删除期间新增的子会话也可能留存，建议先结束相关任务。主文件被外部删除后，本次列表保存的 ID 仍可用来删除其后代。

目录不存在、无会话、读取失败或损坏行会有提示；链接目录和文件被跳过。文件被占用时可能无法删除，可关闭使用该文件的程序后重试。

如需测试，可在 PowerShell 中指定独立目录；该目录即扫描和删除范围：

```powershell
.\CodexSessionCleaner.exe --sessions-root 'D:\临时会话'
```
