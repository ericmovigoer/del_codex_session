## 核心验证范围

- 递归扫描、中文路径、不同目录同名文件、修改时间倒序、大小写扩展名、空目录、缺失目录。
- UTF-8 BOM、中文、多行文字、少于和超过 5 条消息、文字片段合并、空文件、无效 UTF-8 和损坏 JSON 行。
- 过滤配置、工具调用、事件记录副本、非用户/助手角色及无文字内容。
- 扫描和预览取消，包括读取期间取消。
- 取消删除、确认删除、外部删除、只读文件和文件占用导致的失败。
- 拒绝非 JSONL、目录、目录外路径、路径穿越、相似前缀目录、目录链接及链接根目录。
- 根目录带末尾分隔符时扫描与删除。
- 列表只统计 cli / vscode 交互主会话；隐藏子 Agent、孤立子 Agent、exec、mcp 和未知来源；普通 fork 仍作为独立主会话。
- 取消保留整组文件；递归删除跨日期目录的全部子孙，包含列表加载后、删除确认前新增的子文件；无关主会话、普通 fork 及孤立记录保留。
- 缓存主会话 ID 可在主文件被外部删除后清理其后代；拒绝直接删除隐藏子 Agent。
- 元数据损坏、重复 ID、主会话身份变化时阻止删除；子文件失败保留主文件；部分删除报告文件数量并可重试。
- 使用仅属性写权限反复设置/清除根目录 junction，同时进行 300 次删除尝试；目录外哨兵文件保留。

## 界面验证范围

通过 Windows 消息自动化驱动实际 MFC 程序，仅定位新启动测试进程的窗口：

- 未选择时禁用删除；读取完整路径、中文和多行预览。
- 对较大文件与短文件快速交替选择 20 轮，旧预览没有覆盖当前预览。
- 四个 JSONL 文件（两个主会话、一个子 Agent、一个孙 Agent）仅显示两个主会话。
- 确认弹窗显示完整路径及所有层级子 Agent 的删除范围，默认按钮为“取消”；取消后整组文件保留。
- 最深层子文件只读时删除失败，提示原因且保留整组文件及主会话列表项。
- 确认后实际删除主会话及子孙文件，另一主会话不受影响；更新列表、清空预览并禁用删除按钮。
- 文件被外部删除后同步更新列表。
- 刷新空目录显示提示；后台任务正常退出。

上述删除检查全部使用唯一临时目录中的测试文件。未删除真实 Codex 会话；未对 Codex 索引、历史记录文件或数据库进行写入。

## 独立审查

审查覆盖后台线程退出、结果版本检查和删除路径安全。已修复退出通知竞态及根目录末尾分隔符问题；删除现在以持有的根目录句柄为基准核对文件实际路径，并在删除前复核目录链。修复后复核通过。

本次另行只读审查了元数据关联、删除顺序和错误提示。每个文件删除前通过持有的文件句柄重新检查会话身份及父子关系。已知限制：数据库/缓存条目可能与文件筛选结果不同；中间层文件预先丢失、删除期间持续新增子会话时，单次文件扫描不能保证清理全部后代。
